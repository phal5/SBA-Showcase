### 1. `FragmentationHeaderRecord` 속성 주석의 반환값 타입 자기모순
- **유형**: 자기모순
- **어디**: `src/Assembly/Records/FragmentationHeaderRecord.cs:41-42` 및 `src/Assembly/Records/FragmentationHeaderRecord.cs:64, 85`
- **무엇이 어긋나는가**: 
  - `src/Assembly/Records/FragmentationHeaderRecord.cs:41-42` 주석에서는 `UniformFragmentPayloadBytes` 속성에 대해 `"Meaningless unless <see cref=\"FindDeclaredInvariantViolation\"/> returned null."`이라고 기술하고 있습니다.
  - 그러나 실제 `FindDeclaredInvariantViolation()` 메서드(`line 64-86`)의 반환 타입은 `DropReason` 열거형(enum) 값 타입이며, 불변식이 모두 만족될 때 `DropReason.None`을 반환합니다. `null`은 반환될 수 없는 타입입니다.
- **재현 방법**:
  `FragmentationHeaderRecord.cs` 소스 코드 42행과 64행을 대조 확인. `FindDeclaredInvariantViolation()`의 반환값은 열거형이므로 호출자가 `null`과 비교하면 컴파일 에러가 발생하며, `DropReason.None`과 비교해야 합니다.

### 4. `SealedDatagramSendPipeline`에서 비정상 분할 플랜 입력 시 크기 검증 전 버퍼 오버플로 예외 발생
- **유형**: 미강제 불변식
- **어디**: `src/Security/Pipelines/SealedDatagramSendPipeline.cs:77-87`
- **무엇이 어긋나는가**:
  - E3 및 설계 원칙에 따르면 엔진의 송수신 파이프라인은 잘못된 크기/형식의 입력에 대해 예외를 던지지 않고 거절 판정(`Verdict.Reject`)을 반환해야 합니다.
  - 그러나 `SealedDatagramSendPipeline.WriteSealedFragmentDatagram`은 1단계(`line 77-78`)에서 고정 크기 스크래치 버퍼 `_sealedAreaScratch` (크기 `MaxSealedAreaBytes` = 1,374)에 `MessageFragmentationPipeline.WriteFragmentCarrier`를 통해 직렬화를 먼저 수행한 뒤, 2단계(`line 87`)에서 비로소 `datagramLength > MaxSealedDatagramBytes`를 검사합니다.
  - 만약 호출자가 `UniformFragmentPayloadBytes`가 버퍼 허용치(1,362 B)보다 큰 비정상 `MessageSplitPlanRecord`를 전달할 경우, 2단계의 거절 판정에 도달하기 전에 1단계의 `Span.CopyTo` / `Slice`에서 `ArgumentOutOfRangeException` 예외가 발생합니다.
- **재현 방법**:
  다음 테스트 코드를 실행:
  ```csharp
  var plan = new MessageSplitPlanRecord(40_000, 20, 2_000); // UniformFragmentPayloadBytes = 2,000
  byte[] message = new byte[40_000];
  byte[] datagram = new byte[2_500];
  world.Seal.WriteSealedFragmentDatagram(0xA1, plan, 1, 0, message, datagram);
  ```
  결과: `Verdict.Reject(DropReason.SealedDatagramLengthOutOfRange)`가 반환되지 않고 `MessageFragmentationPipeline.WriteFragmentCarrier` 내부의 `carrier.Slice(FragmentationHeaderRecord.WireBytes, length)`에서 `ArgumentOutOfRangeException` 예외가 던져짐.
- **확신도**: 확신
